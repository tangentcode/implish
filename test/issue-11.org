Regression tests for tangentcode/implish#11. Run with =npm test=.

* Issue #11: shown dicts and lists read back the same

The loader reads =`c,= as the symbol =c,=, so the writer must never put
a comma straight after a symbol. These tests check that =value show x=
gives back =x= (=match= is 1) for every value type inside dicts and lists.
Lists are passed by get-word (=:l=) so the stored value is shown as is.

** TEST dict-sym-value : symbol value keeps its key
#+begin_src
> d: :[`c `d]
:[`c `d]
> keys value show d
`c
> match[d; value show d]
1
#+end_src

** TEST dict-syms-value : symbol-vector value keeps its key
#+begin_src
> d: :[`e `f `g; `h 1]
:[`e `f `g; `h 1]
> keys value show d
`e `h
> (value show d)`e
`f `g
#+end_src

** TEST dict-null-sym-value : null-symbol value keeps its key
#+begin_src
> d: :[`k `]
:[`k `]
> match[d; value show d]
1
#+end_src

** TEST dict-nested : symbol value in a nested dict
#+begin_src
> d: :[`k :[`m `x]]
:[`k :[`m `x]]
> match[d; value show d]
1
> match[d; value show value show d]
1
#+end_src

** TEST dict-all-types : every value type round-trips inside a dict
#+begin_src
> e: :[`i 1 2; `n 1.5; `s "a b"; `z nil; `l [1 "a"]; `y `p `q; `d :[`k `v]; `f {x * 2}]
:[`i 1 2; `n 1.5; `s "a b"; `z nil; `l [1 "a"]; `y `p `q; `d :[`k `v]; `f {x * 2}]
> match[e; value show e]
1
#+end_src

** TEST list-of-syms : separate symbols in a list stay separate
#+begin_src

[`a; `b]

** TEST list-of-nums : separate numbers in a list stay separate
