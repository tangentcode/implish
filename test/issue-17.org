#+title: issue #17 regression tests: error and multi-line string values

Multi-line strings use the triple-backtick syntax the README documents,
and =show= writes them so they read back the same. A read failure is an
error (catchable with =try=), never a value with no syntax of its own.

* TEST mls-load : a ``` string loads as one multi-line string
#+begin_src
> m: value rd %test/fixtures/mls.imp
```
hi
there
```
> type? :m
mls!
> match[:m; value show :m]
1
> type? value show :m
mls!
#+end_src

* TEST mls-repl-lines : a ``` string can span REPL lines
#+begin_src
> m: ```
> a
>   b
> ```
```
a
  b
```
> show :m
"```\na\n  b\n```"
> match[:m; value show :m]
1
#+end_src
